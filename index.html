How I work

Agentic workflows that multiply my output.

I build my own AI workflows for planning, execution and testing. They move the repetitive work fast, which frees my time for what matters: architecture, review and the craft that goes into every release.

  1. 01

    Plan

    Specs are pulled straight from Figma and mapped to a prop API, design tokens and file layout before any code is written.

  2. 02

    Execute

    A dedicated builder agent implements against the plan, with progress saved to disk so work survives across sessions.

  3. 03

    Test

    Unit tests in Vitest and end-to-end runs in Playwright, inside an isolated Docker environment I set up.

  4. 04

    Review & ship

    An AI review skill I wrote flags drift from our conventions on every PR. I review every diff; CI ships the rest.

Craft

My own standards, on every line.

AI makes me faster, but quality is on me. Whoever writes the first draft, every change I ship meets the same bar: clean, organized and built to work as a whole.

The bar

Fast is good. Right is the standard.

Systems, not one-offs

Components are built as a set that shares patterns and works together gracefully, so the whole product feels like one thing.

Every state accounted for

Loading, empty, error and success are handled across the whole flow, not just the screen in the mockup.

Componentized and organized

Small, focused files in a structure that makes sense, so anything can be found in seconds.

DRY, without the clever tricks

Shared logic lives in one place. Abstractions appear only when they make the code simpler.

Readable first

Clear names and small functions: code the next developer understands on the first read.
